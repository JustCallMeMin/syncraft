trying to achieve and how release readiness is judged.

- [`user-journeys-demo-script.md`](./user-journeys-demo-script.md)
  Demo-facing user journeys and scripted walkthrough order.
- [`v1-nfr-baseline.md`](./v1-nfr-baseline.md)
  Minimum non-functional baseline for v1 validation and demo-readiness.
