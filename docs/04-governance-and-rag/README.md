# Governance And RAG

Use this folder for local guidance that helps employees contribute docs in a way
that stays aligned with Syncraft's Notion memory model.

- [`local-documentation-workflow.md`](./local-documentation-workflow.md)
  Practical local workflow for reading and updating docs.
- [`rag-memory-map.md`](./rag-memory-map.md)
  Local mirror of the major memory layers so contributors know where knowledge belongs.

This folder is intentionally small. It should guide contributors toward the right
canonical documents rather than duplicate them.
